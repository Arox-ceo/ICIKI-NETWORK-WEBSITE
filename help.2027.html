Aturan Support

Agar layanan berjalan tertib dan efektif, harap patuhi aturan berikut.

  • Gunakan layanan support hanya untuk kebutuhan yang relevan dengan Server Minecraft ICIKI NET.
  • Gunakan bahasa yang sopan dan jelas.
  • Dilarang menyalahgunakan support untuk kepentingan pribadi yang tidak relevan dengan Server Minecraft ICIKI NET.
  • Bersabar menunggu respons tim support. Kami akan membalas secepat mungkin.
  • Dilarang memberikan informasi palsu atau memanipulasi bukti.

Jenis Support

Masalah yang bisa ditangani Support Center ICIKI NET.

Laporan Pemain

Untuk melaporkan pemain yang melanggar aturan server.

  • Player rusuh
  • Scamming atau penipuan
  • Griefing (merusak properti orang lain di luar aturan)
  • Abusing bug
  • Username atau skin yang tidak sesuai aturan

Laporan Staff

Untuk melaporkan staff yang menyalahgunakan wewenang atau tidak profesional.

  • Penyalahgunaan kekuasaan (abuse command)
  • Ketidakadilan dalam menegakkan aturan
  • Perilaku tidak pantas atau toxic
  • Tidak responsif terhadap pemain yang butuh bantuan

Bug & Masalah Teknis

Untuk melaporkan bug yang mengganggu permainan.

  • Bug terkait item, mekanik, atau fitur server
  • Bug exploit yang bisa disalahgunakan pemain
  • Kesalahan sistem yang menyebabkan crash atau error
  • Lag berlebihan, error koneksi, atau plugin tidak berfungsi

Refund Item Hilang

Pengembalian item yang hilang akibat bug atau rollback server. Lihat syarat lengkap di bagian Refund.

Bantuan Akun

Masalah terkait akun pemain di server.

  • Lupa password akun
  • Akun terkunci atau dibanned secara tidak adil
  • Ganti username yang menyebabkan data hilang
  • Kesulitan registrasi atau login

Unban & Banding Hukuman

Jika kamu merasa dihukum tidak adil.

  • Permintaan unban jika dihukum secara tidak sah
  • Banding hukuman seperti mute, kick, atau jail
  • Peninjauan ulang keputusan tim staff

Pembelian & Donasi

Bantuan terkait transaksi dalam server.

  • Masalah pembelian rank atau item premium
  • Tidak menerima item setelah transaksi
  • Konfirmasi pembayaran dan status donasi

Pertanyaan Umum

Pertanyaan atau panduan seputar server.

  • Cara bermain dan memahami mekanik server
  • Informasi fitur atau event server
  • Memahami aturan dan kebijakan

Kebijakan Refund Item Hilang

Refund hanya untuk item yang hilang akibat bug atau rollback server.

Laporan refund maksimal 24 jam setelah kejadian. Lewat dari itu, laporan tidak dapat diproses.

Syarat Refund

  • Item hilang karena bug, bukan karena kesalahan sendiri
  • Ada bukti kepemilikan item
  • Dilaporkan maksimal 24 jam setelah kejadian

Refund Tidak Berlaku Untuk

  • Kehilangan akibat kematian di game (misalnya jatuh ke lava)
  • Kehilangan karena scamming atau pencurian (kecuali ada bukti kuat)
  • Item hilang akibat kesalahan sendiri, seperti drop tanpa sengaja

Pertanyaan Umum

Bagaimana cara masuk ke server?

Pakai Minecraft Java versi 1.20.1, lalu tambahkan server dengan IP . Edisi Bedrock tidak didukung. Panduan lengkap ada di halaman utama.

Saya tidak bisa terhubung ke server

Cek dulu status server, lalu pastikan versi game 1.20.1 dan IP sudah benar. Kalau server online tapi tetap gagal, kirim screenshot pesan error ke Discord.

Bagaimana cara membeli rank atau gems?

Buka halaman Toko, pilih produk yang kamu mau, lalu ikuti langkah pembayarannya.

Rank atau gems belum masuk setelah bayar

Kirim username Minecraft, produk yang dibeli, dan bukti pembayaran lewat Discord atau email. Tim kami akan memeriksanya.

Bagaimana melaporkan pemain curang atau bug?

Buka tiket di Discord dan kirim username pelaku (atau deskripsi bug), waktu kejadian, dan screenshot atau video sebagai bukti.

Item saya hilang. Bisa direfund?

Bisa, jika hilang karena bug atau rollback server, ada bukti kepemilikan, dan dilaporkan maksimal 24 jam setelah kejadian. Lihat kebijakan refund untuk detailnya.

Apa ketentuan pembelian?

Ketentuan lengkap ada di halaman Syarat Layanan. Kalau ada masalah dengan pembelianmu, hubungi kami lebih dulu.
